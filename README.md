# Beauty with me - Cosmetics Mobile Application

**Beauty with me** is a professional cosmetics E-commerce mobile application built with Flutter. It provides a seamless shopping experience with a comprehensive Admin panel for store management and a user-friendly interface for customers.

## 🚀 Key Features

### User Side
* **Authentication:** Secure Sign Up and Login system using Supabase Auth.
* **Home Page:**
    * **Promotion Slider:** Auto-playing banner for featured sales.
    * **Shop by Brand:** Browse products categorized by brand.
    * **New Arrivals:** Dynamic section that automatically fetches and displays the latest product entries.
    * **Popular Products:** Highlights the top 4 best-selling items.
* **Product Details:** Detailed product view with quantity adjustment.
* **Wishlist & Cart:** Save favorites to a wishlist and manage items in the shopping cart.
* **Search:** Quick product search functionality.
* **Order Management:** Easy checkout process with address details and order history tracking.

### Admin Side
* **Management:** Full control to Create, Read, Update, and Delete (CRUD) for Products, Categories, and Offers.
* **Data Oversight:** Centralized management for Users, Orders, Products, and Offers.
* **Real-time Sync:** Admin changes reflect instantly on the user side.

## 🛠 Tech Stack
* **Frontend:** Flutter (Dart)
* **State Management:** Built-in Flutter Local State (setState, FutureBuilder, StreamBuilder)
* **Backend/Database:** Supabase
* **Authentication:** Supabase Auth
